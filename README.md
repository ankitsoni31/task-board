# Task Board

A simple and clean task management web app to organize your daily tasks.

## 🚀 Features
- Add new tasks with title and description
- Drag and drop tasks between columns
- Delete tasks easily
- Task count updates automatically
- Data saved using Local Storage (no data loss on refresh)
- Responsive design (works on mobile & desktop)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📂 How to Use
1. Click on **Add Task**
2. Enter title and description
3. Drag tasks between columns (To Do, Progress, Done)
4. Delete tasks if needed
5. Your data will be saved automatically
